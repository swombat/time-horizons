# If the slope holds

METR's [time-horizon](https://metr.org/time-horizons/) data, with the GPT-4o → Claude Mythos Preview slope extrapolated to the end of 2030, and some invented future models placed along it. Just for fun — not a forecast.

Live: https://time-horizons.danieltenner.com

- `data.json` / `data.js` — p50/p80 horizons + CIs from METR's `benchmark_results_1_1.yaml` (Horizon v1.1, fetched 2026-08-29)
- `index.html` — the chart (d3, no build step)
